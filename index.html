About

Scratchlet is a private Blooket server created by the Scratchlet Dev Team. This website is fully made out of html, css, and javascript and any art here is made by the website scratch/turbowarp. (Inspired by Blooket, Blacket, and Scratch) The original version of Scratchlet is in Scratch indeed! Have fun.

Features

Collect: Build your collection and discover rare items.
Trade: Trade items with friends and grow your inventory.
Chat: Connect with the community and make new friends.
Play: Enjoy games and earn rewards along the way.

Updates

Version 4 is live with smoother animations and a brand new UI layout!
Added dynamic typing banner and interactive notebook tabs.
Keep checking back for more community events and game additions!
